# Lesson 20 — 5–35 MHz Wideband Characterization

**Phase:** 5–35 MHz NVIS Capstone | **Target:** 2–3 hr plus compute

## Objective
Characterize one physical antenna continuously across 5–35 MHz.

Start with checkpoints at 5, 7, 10, 15, 20, 25, 30, and 35 MHz, then use a finer sweep. Increase resolution around resonances, rapid impedance changes, and pattern transitions.

## Electrical outputs versus frequency
Plot R, X, VSWR, accepted-power fraction, efficiency when available, and realized gain when available.

## Radiation outputs
Derive zenith gain, gain at 60/70/80 degrees, peak elevation, P_high, P_low, high/low ratio, and high-elevation azimuth variation.

## Centerpiece visualization
Create:

```
G(f, elevation)
```

For azimuth-dependent structures explicitly state whether the heatmap represents one azimuth cut, azimuth average, azimuth maximum, or an integrated quantity.

## Transition log
Record frequencies where a zenith maximum becomes a null, new lobes appear, peak elevation shifts rapidly, currents change mode, or impedance changes sharply.

For every important transition inspect element currents and explain the radiation change physically.

## Deliverable
Raw data, reproducible plots, heatmap, transition log, model revision, numerical settings, and interpretation.
