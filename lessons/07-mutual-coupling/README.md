# Lesson 7: Mutual Coupling

**Target time:** 60–75 minutes

## Objective
Understand that nearby antennas are not independent circuit loads.

## Experiment
Use two parallel dipoles. Excite one and observe quantities associated with the second element while varying separation.

Suggested spacing:

```
0.1λ, 0.25λ, 0.5λ, 1.0λ
```

Record the driven element's input impedance and compare patterns.

## Questions
1. Why does an unmodified driven element acquire a different input impedance?
2. At what spacing does coupling become negligible for your chosen metric?
3. Is "negligible" a universal number?
4. What does this imply for arrays, colocated antennas, platforms, and calibration?

## Challenge
Compare the isolated dipole result with the two-element result at the same operating frequency.

## Deliverable
Provide the impedance-versus-spacing result, representative patterns, and your engineering definition of negligible coupling for this experiment.
