# Lesson 14 — Low Horizontal Dipole as an NVIS Baseline

**Phase:** HF/NVIS Engineering  
**Target time:** 90 minutes

## Objective

Establish the simplest useful NVIS reference antenna: a low horizontal dipole.

This becomes the baseline against which more deployable or broadband structures will be compared.

## Experimental variables

Study:
- frequency;
- physical height;
- h/lambda;
- soil.

Start with one variable at a time.

## Height sweep

At selected frequencies, test several heights such as:

```
0.05 lambda
0.10 lambda
0.15 lambda
0.25 lambda
0.50 lambda
```

Record:

| h/lambda | R | X | Zenith gain | Peak elevation | Gain at 60° |
|---:|---:|---:|---:|---:|---:|
| | | | | | |

## Angular metrics

Do not report only peak gain.

Record gain at:
- 0°/near horizon as appropriate to solver convention;
- 15°;
- 30°;
- 45°;
- 60°;
- 70°;
- 80°;
- 90°.

Confirm coordinate conventions before interpreting these values.

## Pattern topology

Identify when the elevation pattern:
- has one broad high-angle lobe;
- develops a zenith null;
- develops multiple lobes.

Explain these transitions using electrical height and interference with the reflected field.

## 5–35 MHz preview

Choose one practical physical height and run the antenna at:

5, 7, 10, 15, 20, 25, 30, 35 MHz.

The antenna does not need to be resonant at every point. The purpose is to observe the **radiation behavior of one physical deployment across the band**.

## Deliverable

Produce:
- height study;
- frequency study;
- comparable elevation plots;
- table of high-angle metrics;
- explanation of where the simple low dipole succeeds and fails.

## Design question

If your only objective were strong overhead radiation at one frequency, what height would you investigate further?

Then explain why that answer does not automatically solve the 5–35 MHz requirement.
