# Lesson 6: Two-Element Array and Interference

**Target time:** 60 minutes

## Objective
Use a two-element array to connect EM simulation with phase, interference, and beam formation.

## Build
Start with two identical parallel dipoles. Place their centers approximately half a wavelength apart.

Excite both elements.

Run three cases:
1. equal amplitude, 0° relative phase
2. equal amplitude, 180° relative phase
3. equal amplitude, 90° relative phase

## Predict first
Before each run, sketch where you expect constructive and destructive interference.

## Questions
- Why can the pattern change dramatically without changing either dipole's physical shape?
- What determines the phase difference seen by a distant observer?
- How does element spacing interact with feed phase?
- What are grating lobes conceptually?
- Why might the feed impedance of one element change when the second element is introduced?

That last question introduces **mutual coupling**.

## Challenge
Change spacing while holding phase constant. Find a case where your simple intuition about two isolated antennas begins to fail.

## Deliverable
Submit predictions, simulated patterns, the completed table, and an explanation of one disagreement between your initial prediction and simulation.
