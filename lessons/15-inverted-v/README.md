# Lesson 15 — Inverted-V Geometry

**Phase:** HF/NVIS Engineering  
**Target time:** 90 minutes

## Objective

Understand the trade between a horizontal dipole and a deployable center-supported inverted-V.

## Geometry parameters

Define:
- apex height;
- endpoint height;
- half-element length;
- included angle;
- wire radius;
- feed location.

Draw the geometry and coordinate axes before modeling.

## Prediction

Compared with a horizontal dipole of similar total wire length:

1. How might sloping the elements affect feed impedance?
2. How might it change polarization components?
3. How might it affect azimuth uniformity?
4. Why is an inverted-V attractive for field deployment?

## Lab A — controlled comparison

Compare:
- horizontal dipole;
- shallow inverted-V;
- steeper inverted-V.

Keep total wire length and apex location controlled where possible.

Record:
- R+jX;
- resonance;
- zenith gain;
- peak elevation;
- azimuth variation at a selected high elevation.

## Lab B — apex height

Sweep apex height while retaining the same wire geometry concept.

Express each height as h/lambda.

## Lab C — endpoints

Change endpoint height/stake geometry.

This is both an antenna-design variable and a deployment-tolerance variable.

## Deliverable

Provide:
- geometry sketches;
- impedance table;
- elevation patterns;
- high-elevation azimuth cuts;
- deployment discussion.

## NVIS connection

A center-supported sloping antenna may sacrifice some idealized behavior in exchange for rapid deployment. The final design must evaluate that trade quantitatively rather than assuming either geometry is superior.
