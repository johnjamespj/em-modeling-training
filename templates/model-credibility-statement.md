# Model Credibility Statement

## 1. Intended use
State the engineering decision or question this model supports.

## 2. Model description
Briefly describe geometry, excitation, frequency range, environment, and important material assumptions.

## 3. Physics sanity checks
List analytical estimates or known qualitative behavior used as independent checks.

## 4. Numerical verification
Document:
- segmentation study;
- frequency resolution;
- convergence criteria;
- solver warnings;
- any numerical limitations.

## 5. Physical validation
State what has been compared with:
- measurement;
- independent solver;
- published/analytical reference;
- known hardware behavior.

If none, say so explicitly.

## 6. Sensitivities
Identify parameters that materially affect the result.

## 7. Known omissions
List physical effects absent from the model.

## 8. Credible conclusions
State what the model can reasonably support.

## 9. Non-credible conclusions
State what the model should not be used to claim.

## 10. Next validation step
What single test would most increase confidence?
